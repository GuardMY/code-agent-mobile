# VS Code 配对连接合并设计

**目标：** 将 VS Code 侧边栏底部原本分开的 `扫码连接第一台移动设备` 与 `配对信息` 合并为一张统一的 `配对连接` 卡片，并始终在同一处同时展示二维码和配对 JSON。

**范围**

- 保持配对区域仍位于 VS Code 侧边栏底部。
- 用一个合并后的面板替换当前分开的 `扫码连接第一台移动设备` 和 `配对信息` 面板。
- 无论是否已经有移动设备完成配对，标题都固定为 `配对连接`。
- 当存在可用配对数据时，在同一张卡片内同时显示说明文案、二维码和配对 JSON。
- 保持现有的局域网控制面板独立，不并入该卡片。

**设计**

- 将改动限制在 VS Code webview 渲染层，避免影响 host、protocol 和移动端逻辑。
- 用一个新的 `pairing-connection-panel` 替换当前页脚中的配对入口面板和配对信息面板。
- 去掉基于活跃设备数量切换标题的逻辑，使合并后的卡片始终使用 `配对连接`。
- 当 `pairingJson` 能解析出有效的配对信息时，在卡片中先渲染一段简短说明，再依次渲染二维码区块和 JSON 区块。
- 当配对数据不可用时，仍保留这张合并卡片，并显示空态说明，而不是继续渲染第二张详情卡片。
- 保持底部区域顺序为：主仪表盘内容之后先渲染合并后的配对卡片，再渲染局域网控制卡片。

**测试**

- 为 webview 增加覆盖，断言合并后的 `配对连接` 面板只渲染一次，并且同时包含二维码区域和配对 JSON 内容。
- 增加断言，确保旧的独立标题 `扫码连接第一台移动设备`、`添加设备` 和 `配对信息` 不再出现。
- 改动完成后将 VS Code 插件打包为 VSIX。
