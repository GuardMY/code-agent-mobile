# VS Code 会话详情自动滚动设计

**目标：** 让 VS Code 插件中的会话详情在合适的时机始终显示最新消息，同时不打断正在查看旧消息的用户。

**范围**

- 首次打开某个会话详情时，自动滚动到最新消息。
- 插件用户发送消息后，自动滚动到最新消息。
- agent 输出到达时，只有在更新前详情原本已接近底部时才自动滚动。
- 如果 agent 输出到达时用户正在查看较早的消息且不在底部，则保持当前位置不变。

**设计**

- 将滚动跟随逻辑保留在 webview 层，因为它属于和消息容器绑定的表现层状态。
- 为会话消息容器增加稳定的标识，并在 webview 脚本中加入轻量的滚动状态跟踪。
- 跟踪当前选中会话是否已首次展示，以及消息容器当前是否接近底部。
- 在选择会话和用户发送消息时触发滚动到底部。
- 当新事件触发 webview 重渲染时，仅在上一次渲染状态表明用户原本就在底部附近的情况下跟随 agent 新消息。

**测试**

- 为会话详情容器渲染和滚动行为钩子补充 webview 测试。
- 如有需要，为用户发送消息后的事件顺序补充 extension 测试，确保在 host 更新到达前，最新用户消息已出现在列表末尾。
- 改动完成后将 VS Code 插件打包为 VSIX。
